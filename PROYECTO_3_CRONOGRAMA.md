# CRONOGRAMA DETALLADO - PROYECTO 3: VIDEOTUTORIALES PATRIMONIO CULTURAL

## Serie de 8 Videos Educativos Verticales - Lima 2025

---

## 1. RESUMEN EJECUTIVO

**Duración Total:** 26 semanas (Julio - Diciembre 2025)  
**Fecha Inicio:** 1 de julio de 2025  
**Fecha Cierre:** 15 de diciembre de 2025  
**Cantidad de Videos:** 8 episodios (30-60 segundos cada uno)  
**Formatos:** TikTok, Instagram Reels, YouTube Shorts

---

## 2. FASES PRINCIPALES

### FASE 1: PREPRODUCCIÓN (Semanas 1-8)
**Julio - Agosto 2025**

```
WEEK 1-2 (JUL 1-14): INVESTIGACIÓN Y BENCHMARKING
├─ Lunes 1: Kick-off meeting
├─ Análisis de contenidos patrimoniales virales
│  └─ Top 50 videos sobre patrimonio en TikTok/IG
│  └─ Análisis de engagement, duración, formato
├─ Entrevistas con educadores
├─ Focus groups para definir temas
└─ Selección preliminar de 12 temas candidatos

WEEK 3-4 (JUL 15-28): SELECCIÓN DEFINITIVA Y RESEARCH
├─ Análisis cuantitativo de viralización
├─ Selección final: 8 temas de 12 candidatos
├─ Investigación patrimonial profunda
│  ├─ Tema 1: Machu Picchu (historia, cultura)
│  ├─ Tema 2: Textiles Ancestrales (técnicas)
│  ├─ Tema 3: Quipu (sistema de registro)
│  ├─ Tema 4: Gastronomía Precolombina
│  ├─ Tema 5: Cerámica Moche
│  ├─ Tema 6: Ruta del Inca
│  ├─ Tema 7: Leyendas Peruanas
│  └─ Tema 8: Patrimonio Urbano (Barranco)
├─ Entrevistas con expertos por tema
└─ Recopilación de materiales de referencia

WEEK 5-6 (JUL 29-AUG 11): DESARROLLO DE GUIONES
├─ Redacción de 8 guiones técnicos
│  └─ 45-60 segundos cada uno
│  └─ Indicaciones de visuals, transiciones, audio
├─ Storyboarding visual
│  └─ Dibujos/notas de shots clave
└─ Revisión y aprobación de guiones

WEEK 7-8 (AUG 12-25): PLANIFICACIÓN TÉCNICA Y SCOUTING
├─ Identificación de locaciones
│  ├─ Machu Picchu (o stock footage)
│  ├─ Museo (textiles, cerámica)
│  ├─ Barranco/murales
│  ├─ Estudios (set para Quipu)
│  └─ Mercados/locaciones gastronómicas
├─ Scouting físico y fotografía
├─ Obtención de permisos de rodaje
├─ Planificación de viajes
├─ Coordinación de contactos patrimoniales
└─ Confirmación de equipo técnico

WEEK 9 (AUG 26-30): CONSOLIDACIÓN
├─ Documento de preproducción final
├─ Checklist de equipamiento
├─ Presupuesto confirmado
├─ Equipo confirmed
└─ Licencias y permisos finalizados

✓ HITO: 31 AGOSTO - Documento Preproducción Completo
```

### FASE 2: RODAJE (Semanas 9-16)
**Agosto - Octubre 2025**

```
WEEK 9-10 (AUG 26-SEP 8): RODAJE TEMAS 1-2
├─ Tema 1: MACHU PICCHU EN 60 SEGUNDOS
│  ├─ Lunes-Martes: Preparación y viaje
│  ├─ Miércoles-Viernes: Rodaje principal
│  ├─ Sábado: Cobertura B-roll
│  └─ Entrevista con historiador / guide
│
├─ Tema 2: TEXTILES ANCESTRALES
│  ├─ Locación: Museo o taller artesanal
│  ├─ Lunes: Rodaje de manos tejiendo
│  ├─ Martes: Entrevista con artesana
│  ├─ Miércoles: B-roll de productos
│  └─ Backup material si necesario
│
├─ Equipo: Solano (productor) + Camarógrafo + Asistente
├─ Duración: 2 semanas
└─ Rushes: ~8-10 horas de material

WEEK 11-12 (SEP 9-22): RODAJE TEMAS 3-4
├─ Tema 3: QUIPU - SISTEMA DE REGISTRO INCA
│  ├─ Locación: Estudio (set con réplica de quipu)
│  ├─ Demostración de cómo funcionaba
│  ├─ Animación/motion graphics integration
│  └─ Entrevista con experto
│
├─ Tema 4: GASTRONOMÍA PRECOLOMBINA
│  ├─ Locación: Mercado + cocina
│  ├─ Preparación de platos ancestrales
│  ├─ Entrevista con chef/historiador
│  ├─ Close-ups de ingredientes
│  └─ Degustación/reacciones
│
├─ Duración: 2 semanas
└─ Rushes: ~8-10 horas de material

WEEK 13-14 (SEP 23-OCT 6): RODAJE TEMAS 5-6
├─ Tema 5: CERÁMICA MOCHE - TÉCNICAS MILENARIAS
│  ├─ Locación: Museo o taller ceramista
│  ├─ Demostración de técnicas
│  ├─ Close-ups de piezas Moche
│  ├─ Entrevista con arqueólogo
│  └─ Comparación antiguo-moderno
│
├─ Tema 6: LA RUTA DEL INCA - GEOGRAFÍA SAGRADA
│  ├─ Locación: Sitios de la ruta (Cusco, Valle Sagrado)
│  ├─ Establecimientos de geografía
│  ├─ Testimonios de comunidades
│  ├─ Vistas aéreas/drones (si presupuesto)
│  └─ Narrativa de viaje espiritual
│
├─ Duración: 2 semanas
└─ Rushes: ~8-10 horas de material

WEEK 15-16 (OCT 7-20): RODAJE TEMAS 7-8
├─ Tema 7: LEYENDAS PERUANAS - MITOS QUE PERDURAN
│  ├─ Locación: Exteriores + estudios
│  ├─ Dramatización de leyenda (La Pamba, Sirena, etc.)
│  ├─ Testimonios de comunidades
│  ├─ Representaciones visuales
│  └─ Mezcla de documental + narrativo
│
├─ Tema 8: PATRIMONIO URBANO - BARRANCO Y SUS MURALES
│  ├─ Locación: Distrito de Barranco, murales
│  ├─ Entrevista con artistas/historiadores
│  ├─ Recorrido por patrimonio arquitectónico
│  ├─ Street art y evolución cultural
│  └─ Conexión con identidad contemporánea
│
├─ Duración: 2 semanas
└─ Rushes: ~8-10 horas de material

TOTAL RODAJE: 40-50 horas de material en bruto

✓ HITO: 31 OCTUBRE - Rushes Completos Entregados
```

### FASE 3: POSTPRODUCCIÓN (Semanas 17-25)
**Octubre - Noviembre 2025**

```
WEEK 17-18 (OCT 21-NOV 3): VISIONADO Y ORGANIZACIÓN
├─ Visionado completo de 40+ horas de rushes
├─ Clasificación y tagging de clips
│  └─ Por tema, toma número, calidad, notas
├─ Creación de selects (mejores takes)
├─ Organización en timeline preliminar
├─ Identificación de gaps o material faltante
└─ Edición de rough cuts preliminares

WEEK 19-21 (NOV 4-24): EDICIÓN INTENSIVA
├─ SEMANA 19: EDICIÓN VIDEOS 1-3
│  ├─ Montaje de estructura narrativa
│  ├─ Selección de música/sonidos
│  ├─ Integración de transiciones
│  ├─ Ajuste de pacing para 45-60 segundos
│  └─ Primer corte aprobado
│
├─ SEMANA 20: EDICIÓN VIDEOS 4-6
│  └─ Mismo proceso que semana 19
│
├─ SEMANA 21: EDICIÓN VIDEOS 7-8 + RETOQUES
│  ├─ Edición de últimos 2 videos
│  ├─ Revisión general de todos los 8
│  ├─ Ajustes finales de estructura
│  ├─ Agregación de gráficos informativos
│  └─ Sincronización de audio-video

WEEK 22-23 (NOV 25-DEC 8): COLOR Y AUDIO
├─ COLOR CORRECTION (SEMANA 22)
│  ├─ Análisis de exposición por video
│  ├─ Corrección de blancos
│  ├─ Grading creativo (Rec. 709 para vertical)
│  ├─ Normalización de color entre clips
│  └─ Optimización para plataformas móviles
│
├─ SONORIZACIÓN Y MEZCLA (SEMANA 23)
│  ├─ Ajuste de audio sincrónico
│  ├─ Incorporación de música de fondo
│  ├─ Diseño sonoro (efectos, foley)
│  ├─ Mezcla de niveles (-23 LUFS normalización)
│  ├─ Revisión final de audio
│  └─ Exportación de pistas separadas

WEEK 24-25 (DEC 9-15): SUBTÍTULOS Y EXPORTACIÓN
├─ SUBTITULADO (SEMANA 24)
│  ├─ Transcripción de diálogos (8 videos)
│  ├─ Creación de SRT en español
│  ├─ Traducción al inglés
│  ├─ Timing preciso de subtítulos
│  ├─ Revisions ortográficas
│  └─ Burned-in text en versión final
│
├─ EXPORTACIÓN POR PLATAFORMA (SEMANA 25)
│  ├─ TikTok: MP4 1080x1920 (vertical)
│  ├─ Instagram Reels: MP4 1080x1920 (vertical)
│  ├─ YouTube Shorts: MP4 1080x1920 (vertical)
│  ├─ Master ProRes: 2160x3840 (archival)
│  └─ Verificación de calidad en todas versiones

✓ HITO: 30 NOVIEMBRE - 8 Videos Master Finalizados
```

## 5. BUFFER Y CONTINGENCIAS

**Colchones de Tiempo Planificados:**
- Preproducción: +0.5 semanas (investigación)
- Rodaje: +2 semanas (para retrasos/clima/logística)
- Post: +1 semana (para revisiones)
- Distribución: Flexible (publicación puede extenderse a enero)

**Total proyecto:** 26 semanas + 3.5 semanas buffer = 29 semanas
